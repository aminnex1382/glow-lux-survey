# 🌸 راز زیبایی ماندگار | GLOW LUX - سامانه نظرسنجی و نیازسنجی هوشمند

یک وب‌اپلیکیشن فوق‌العاده شیک، واکنش‌گرا (ریسپانسیو) و کاربرپسند با پالت رنگی زنانه و لوکس (رزگلد، صورتی و کرم) برای کانال و محصولات آرایشی-بهداشتی **«راز زیبایی ماندگار | از نگاه علم (GLOW LUX)»**.

---

## 🔒 دسترسی محرمانه به صفحه آمار و نتایج (اسلاگ اختصاصی)

برای حفظ محرمانگی و امنیت آمار:
- **هیچ‌گونه دکمه یا لینکی در صفحه اصلی، هدر یا فوتر برای ورود به بخش آمار وجود ندارد** تا مخاطبان عادی نتوانند به پاسخ‌ها دسترسی داشته باشند.
- برای مشاهده داشبورد آمار و نظرات، کافیست اسلاگ `#/admin` یا `#/glow-admin` را در انتهای آدرس مرورگر وارد کنید:
  - در حالت محلی: `http://localhost:3000/#/admin`
  - در گیت‌هاب پیجز: `https://<username>.github.io/<repo>/#/admin`

## ✨ ویژگی‌های برجسته

1. **طراحی لوکس، زنانه و مدرن (Luxe Feminine Aesthetic):**
   - تم رنگی اختصاصی الهام‌گرفته از رزگلد (`#b76e79` و `#e54576`)، صورتی پودری و کرم
   - کارت‌های Glassmorphism (شیشه‌ای مات) با سایه‌های ملایم و مرزهای نئونی
   - انیمیشن‌های نرم ورود و انیمیشن جشن پایان با فشفشه‌های لوکس (Confetti)
   - فونت زیبای فارسی وزیرمتن (Vazirmatn) با خوانایی فوق‌العاده در موبایل و دسکتاپ

2. **تجربه کاربری مرحله‌به‌مرحله (Step-by-Step Stepper):**
   - صفحه خوش‌آمدگویی جذاب با معرفی کانال و اطمینان از محرمانه بودن پاسخ‌ها (بدون نیاز به نام یا شماره تماس)
   - نمایش تک‌به‌تک سوالات با نوار پیشرفت زنده و درصد تکمیل
   - سوالات چندگزینه‌ای با شماره‌گذاری فارسی و چک‌مارک تعاملی
   - سوال تایپی پایانی برای پیشنهادات و انتقادات با شمارشگر کاراکتر
   - امکان بازگشت به سوالات قبل و ویرایش پاسخ‌ها

3. **سیستم ذخیره‌سازی فایل JSON (`data/responses.json`):**
   - سرور محلی Node/Express برای ذخیره همزمان هر پاسخ درون فایل `data/responses.json`
   - اتصال هوشمند و منعطف (Fallback به LocalStorage در محیط‌های استاتیک نظیر GitHub Pages)
   - حفظ پایدار پاسخ‌ها بدون نیاز به دیتابیس پیچیده

4. **داشبورد جامع آمار و گزارش تحلیلی (Admin Dashboard):**
   - نمایش تعداد کل پاسخ‌دهندگان و آمار زنده
   - تفکیک دقیق هر سوال چندگزینه‌ای:
     - تعداد افراد انتخاب‌کننده هر گزینه (`X نفر`)
     - درصد سهم هر گزینه (`Y%`)
     - نمودار میله‌ای افقی زیبا با هایلایت کردن گزینه برتر و محبوب‌ترین دغدغه (🏆)
   - بخش ویژه نظرات تایپی مخاطبان با قابلیت جستجو، فیلتر و کپی
   - امکان دانلود مستقیم فایل `responses.json`
   - امکان بارگذاری (Import) یا ریست کردن داده‌ها
   - نمایش ساختار خام داده‌ها در قالب کد JSON

## 📋 سوالات گنجانده شده در نظرسنجی

- **بخش اول: سلامت و تناسب اندام**
  - سوال ۱: دغدغه در تناسب اندام (چاقی، لاغری، چربی شکم و پهلو، حفظ وزن و...)
  - سوال ۲: اولویت آموزش سلامت (تغذیه، کنترل وزن، افزایش انرژی، سبک زندگی)
- **بخش دوم: سلامت دهان و دندان**
  - سوال ۳: مشکلات دهان و دندان (بوی نامطبوع، حساسیت، پوسیدگی، زردی و...)
- **بخش سوم: دردهای عضلانی و مفصلی**
  - سوال ۴: مواجهه با دردهای عضلانی/مفصلی (کمر، زانو، مفاصل، گردن، بدون مشکل)
- **بخش چهارم: سلامت و زیبایی مو**
  - سوال ۵: مهم‌ترین دغدغه موها (ریزش، نازکی و کم‌پشتی، خشکی، شوره، رشد کم)
- **بخش پنجم: پوست بدن**
  - سوال ۶: مشکلات پوست بدن (خشکی، تیرگی آرنج و زانو، جوش، لک، شل شدن)
- **بخش ششم: انگیزه، هدف و درآمد**
  - سوال ۷: دغدغه ذهنی کنونی (درآمد، شغل، استقلال مالی، انگیزه و هدف، رشد فردی)
  - سوال ۸: میزان جذابیت فرصت درآمدزایی روزمره
  - سوال ۹: زمینه اولویت رشد فردی
- **بخش هفتم: پیشنهادات و انتقادات (تایپی)**
  - سوال ۱۰: دریافت نظرات و پیشنهادات آزاد مخاطبان به صورت متنی

## 🚀 راهنمای راه‌اندازی و اجرا

### ۱. اجرای سرور توسعه (Local Development)
برای اجرای همزمان بک‌اند ذخیره‌سازی JSON و فرانت‌اند React:

```bash
# ترمینال ۱: اجرای سرور بک‌اند (برای ذخیره در data/responses.json)
node server.js

# ترمینال ۲: اجرای محیط توسعه فرانت‌اند
npm run dev
```

سایت به نشانی `http://localhost:3000` در دسترس خواهد بود.
برای ورود به صفحه آمار: `http://localhost:3000/#/admin`
